# 🪙 How to Get Airdrop Rewards

Through an ecosystem of applications, everyday experts can earn rewards for their meaningful contributions.

## **1. Be an Uploader in the Data Hub**

* **Role**: The Uploaders participate in data campaigns by submitting relevant data.
* **How it Works**:
  * Join specific campaigns launched on the **Data Hub** that request specific types of data (e.g., images, text, audio, etc.).
* **Rewards**:
  * Earn **USDT** for contributions that meet quality standards.
  * Receive **$PUBLIC airdrop points** as additional incentives for high-quality data.

## **2. Be a Voter in the Data Hub**

* **Role**: The voters vote on the quality of uploaded data to ensure it meets campaign requirements.
* **How it Works**:
  * Review the data uploaded by participants and check if it aligns with campaign instructions.
  * Vote on whether the data is a “**hit**” (meets the criteria) or a “**miss**” (does not meet the criteria).
  * Participate in a **consensus-based validation process** (Byzantine Fault Tolerance mechanism) to finalize data quality.
* **Rewards**:
  * Earn **$PUBLIC airdrop points** based on validation accuracy and alignment with the consensus.
  * Higher rewards for voters with a proven track record of accuracy.

***

## **3. Be a Node Operator via the Data Hunter Extension**

* **Role**: Operators run nodes that provide computational resources to support AI agents, helping improve the efficiency and quality of data validation.
* **How it Works**:
  * Install the **Data Hunter extension** and set it up as a node to contribute idle computational resources.
  * Enable AI agents to assist human voters in accelerating quality checks in the Data Hub.
* **Additional Functionality**:
  * Use the “**AI Reply**” button within the extension to interact with popular posts on **X** (formerly Twitter).
  * Generate AI-driven replies to posts, contributing valuable AI feedback data while engaging in social media activities.
* **Rewards**:
  * Mine **$PUBLIC airdrop points** for running the node and using the “**AI Reply**” functionality.
  * Higher mining **$PUBLIC** rewards for more active and consistent participation.
