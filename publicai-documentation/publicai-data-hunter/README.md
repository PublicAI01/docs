# 🏹 PublicAI Data Hunter

[PublicAI Data Hunter](https://chromewebstore.google.com/detail/publicai-data-hunter/icbbdjflabjciapbohkkkmaangfjaanl?utm_source=gitbook) is a seamless data collection tool for **AI Builders** that operates as a Google Chrome Extension.&#x20;

You will need to [login with your PublicAI Data Hub account](download-and-connect-account.md) before you start earning.&#x20;

This seamless Chrome extension allows you to contribute to AI development while earning rewards effortlessly. Simply stay logged in, and your participation helps shape the future of AI. Check your daily gains in the [Data Hub Dashboard](https://beta.publicai.io/dashboard)!\
\
Users can choose to reply to high-quality tweets they come across while browsing X using the new [AI Reply](ai-tool-for-x.md) feature in Data Hunter. Additionally, users can passively earn points by keeping their browser open with the extension installed.&#x20;
